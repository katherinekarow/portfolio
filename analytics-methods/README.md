# Analytical methods
> The analysis techniques behind my projects (clustering, historical and velocity analysis, scatter and regression, statistics and quality control, optimisation) with the maths, the formulas, and tested code.

| Project | Methods |
|---|---|
| [Cluster analysis](cluster-analysis/) | scaling, distance measures, k-means++, choosing k (elbow, silhouette, gap), Ward hierarchical clustering, PCA, adjusted Rand index, outlier flags |
| [Historical & velocity analysis](historical-velocity-analysis/) | weekday-aligned year-over-year, velocity curves and percentiles, pace projection, decomposition, Holt-Winters, MAPE/WAPE/MASE, CUSUM |
| [Scatter & regression](scatter-regression/) | Pearson/Spearman/Kendall, OLS with intervals, log-log elasticity, diagnostics (leverage, Cook's distance, VIF, Breusch-Pagan), Simpson's paradox, robust regression |
| [Statistics & quality control](statistics-quality/) | distributions, confidence intervals, hypothesis tests, control charts (X̄–R, p, CUSUM, EWMA), capability, Pareto/ABC, queueing, Monte Carlo |
| [Optimisation & decisions](optimization-decisions/) | simplex with shadow prices, transportation, knapsack and branch-and-bound, Hungarian assignment, Newton vs gradient, Lagrange, decision trees, EVPI, newsvendor |

Each project explains every method in plain language with its formula, shows where it's used in business, links to the portfolio projects that use it, and runs on synthetic data with tests.
