# Data analysis & BI
> Tableau dashboards, clustering, forecasting and text mining on real-world and sample datasets.

**Opening the files:** `.twbx` files open in [Tableau Public](https://public.tableau.com/app/discover) or Tableau Desktop (free reader: Tableau Reader).
`.rmp` files are RapidMiner Studio processes — open them in RapidMiner to see the full workflow (datasets aren't included).
Each project folder has screenshots so you can preview without installing anything.
