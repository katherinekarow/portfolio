# Predictive models & market-basket analysis in RapidMiner
> Classification and association-rule models built as visual RapidMiner workflows.

**Tools:** RapidMiner Studio (decision trees, linear discriminant analysis, FP-Growth, association rules)

| Process | What it does |
|---|---|
| [`decision-tree.rmp`](decision-tree.rmp) | Trains a decision tree classifier and applies it to new data |
| [`discriminant-analysis.rmp`](discriminant-analysis.rmp) | Linear discriminant analysis after converting categories to numbers |
| [`market-basket-fp-growth.rmp`](market-basket-fp-growth.rmp) | Finds frequently bought-together items and turns them into association rules |
