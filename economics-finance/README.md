# 💹 Economics & finance
> Finance, economics and pricing methods as tested code: a formula toolkit, credit vintage curves, marketing ROI, overbooking economics and a ledger lab.

| Project | What it shows |
|---|---|
| [Formula toolkit](formula-toolkit/) · [calculator](https://katherinekarow.github.io/portfolio/formulas/) | 40 finance, economics and demand-analytics formulas (NPV/IRR, elasticities, curve normalisation, gross vs net targets, credibility weighting), tested and in the browser |
| [Loan vintage curves](loan-vintage-curves/) | credit-portfolio forecasting: cohort default and prepayment curves, chain ladder vs credibility blend, expected loss, loss vs plan |
| [Marketing budget & ROI](marketing-roi/) | response curves with carry-over and saturation, optimal budget split, NPV/IRR/payback, Monte Carlo ROI, A/B test design |
| [Overbooking economics](overbooking-economics/) · [calculator](https://katherinekarow.github.io/portfolio/overbooking/) | optimal booking limits under no-shows: exact profit, the critical-ratio rule, over-dispersion, shrinkage estimates |
| [Ledger vs database lab](blockchain-ledger/) | a working mini-ledger (Merkle proofs, UTXO vs account models, tamper detection, off-chain storage) measured against SQLite |

Everything runs on synthetic data generated by the code, and every project has tests.
