# Small exercises
> Bite-sized programs on loops, input validation and exception handling.

**Tools:** Python

| File | What it does |
|---|---|
| [`digit_sum.py`](digit_sum.py) | Adds up the digits of a positive number |
| [`even_odd_stats.py`](even_odd_stats.py) | Counts and sums even, odd and positive numbers until you enter 0 |
| [`safe_division.py`](safe_division.py) | Shows `try/except` handling for bad input and division by zero |
