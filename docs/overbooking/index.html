Overbooking calculator

A session has a fixed number of slots and some booked patients don't show. Book too few and slots sit empty; book too many and patients who do show have to be rescheduled. This page computes the exact expected profit for every booking limit and picks the best one. All data is synthetic.

Expected profit by booking limit

Profit per session = revenue × patients seen − bump cost × patients bumped, computed exactly from the show-up distribution. The dot marks the best limit.

Empty slots and bumped patients

Both in patients per session. Raising the limit swaps empty slots for bumps; the best limit stops where the next booking's expected bump cost outweighs its expected revenue.

Limits around the best one

How this works
  • Show-ups out of n booked are binomial(n, p); with over-dispersion ρ > 0 the session's show rate itself varies (beta-binomial with the same mean and intra-session correlation ρ), which fattens both tails.
  • Booking one more patient adds p·[r − (r + b)·P(S ≥ C)] for binomial show-ups, so the best limit is the first one where P(at least C show) reaches the critical ratio r / (r + b).
  • With requests ~ Poisson(λ), bookings are min(requests, limit). Demand scales the value of a higher limit but never flips its sign, so the best limit barely moves; the profit it earns falls.
  • The same functions run in Python (overbook.profit), and a browser test checks that this page returns the same best limit and profit for a grid of inputs.
