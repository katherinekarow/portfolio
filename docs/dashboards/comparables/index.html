How this works
  • Distance = 1.0 × (reach differs) + 1.0 × (season differs) + 0.8 × (length differs) + 0.5 × |capacity difference| ÷ capacity range. Ties are broken by session id so the result is repeatable.
  • The proxy is the plain average of the comparables' fill rate at each point before the session. The band shows how much they disagree.
  • The Python version (dashkit.builders.nearest) is the reference; tests check that results come back in distance order and that an exact match ranks first.
