How this works
  • Late demand for each session is modelled as Poisson with a rate that depends on open slots and days remaining; people on the waitlist add to it. P(fill) = P(late demand ≥ open slots).
  • No-shows are expected at each session's historical rate, so a full session can still be overbooked safely by a fraction of its expected no-shows.
  • Actions, in order: overbook full sessions with ≥ 2 expected no-shows → call the waitlist if it covers the gap → partner referral push if P(fill) < 30% within 5 days → SMS nearby patients if P(fill) < 60% → otherwise on track.
