Dashboard gallery

I've built many kinds of dashboards for planning, pricing and operations teams. These are re-creations of the types of dashboard and the logic behind them, rebuilt on invented data from a clinic network and a farm co-op. Every one is interactive, and every number is computed by tested Python code.

How the gallery is built
  • Each dashboard is a static page that reads its own data.json. The JSON is written by python -m dashkit build, so the logic (confidence intervals, Poisson fill odds, displacement pricing, nearest-neighbour search) lives in Python, where it is tested.
  • The two interactive calculators (quote and comparables) also run their maths in the browser; the Python versions are the reference, and the browser tests check they agree.
  • Shared chart code: one colour palette checked for colour-blind safety, one y-axis per chart, tooltips on every chart, and dark mode.
